What Is Open Source Software?

Software whose source code anyone can:

1

Inspect

See exactly how it works

2

Modify

Change it to fit local needs

3

Enhance

Improve it and extend it

4

Share

Use it freely, no licence fees

Source: Raymond, E.S. (1999). The Cathedral and the Bazaar.

Limited Infrastructure

Hardware, electricity and internet remain uneven, especially in rural schools

3

Teacher Training

Many educators have never been trained on open tools

4

Perception and Risk

Concerns about support, security and longevity of community software

Case: Scratch in the Grade 8 Syllabus

Context

The national Grade 8 syllabus, Theme 6: Programming

Learners apply programming principles using Scratch, a free open source tool, and learn its screen areas, blocks and tools

Takeaway

OSS is not new to Namibian classrooms. It is already in the official syllabus.
